An AI-powered job application tracking platform designed to replace disorganized spreadsheets with a smart, centralized dashboard.

* **Core Architecture:** React 19 + FastAPI (Python) + PostgreSQL (Neon) + Google Gemini AI.
* **Key Technical Implementations:**
  * Engineered a secure REST API with JWT authentication, bcrypt password hashing, and strict user-scoped database isolation.

### <a href="https://myinvotrack.vercel.app/"><u>InvoTrack</u></a>

A full-stack invoice management system for small businesses with customer management, billing automation, and revenue analytics.

* **Core Architecture:** Next.js 16 (App Router) + TypeScript + Prisma 7 + PostgreSQL (Neon) + shadcn/ui.
* **Key Technical Implementations:**
  * Built a complete billing workflow with invoice creation, multi-line item support, automatic GST/tax calculation, and discount handling.
  * Implemented server-side PDF generation using jsPDF with branded layout, styled line-item tables, and color-coded status indicators.
  * Designed a real-time dashboard with revenue analytics, invoice status breakdown charts, and clickable recent invoices.
  * Engineered multi-tenant data isolation using userId-scoped database queries, JWT session management, and route-level middleware protection.
  * Developed sequential invoice numbering (INV-001, INV-002), status lifecycle management (UNPAID → PAID/OVERDUE), and full CRUD for customers, products, and invoices.
